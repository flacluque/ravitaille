# Skills de design de Ravitaille

Instructions que Claude Code charge pour travailler sur l'interface. Elles sont installées dans le dépôt pour être
disponibles à chaque session, sur le Mac comme dans le cloud.

| Skill | Source | Licence |
|---|---|---|
| `gsap-core`, `gsap-react`, `gsap-timeline`, `gsap-scrolltrigger`, `gsap-plugins`, `gsap-utils`, `gsap-performance`, `gsap-frameworks` | [greensock/gsap-skills](https://github.com/greensock/gsap-skills) | MIT |
| `design-taste-frontend` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | MIT |
| `transitions-dev`, `transitions-polish` | [Jakubantalik/transitions.dev](https://github.com/Jakubantalik/transitions.dev) | Transitions.dev (usage libre, pas de redistribution comme bibliothèque) |
| `react-bits` | écrit pour Ravitaille, d'après [DavidHDev/react-bits](https://github.com/DavidHDev/react-bits) (pas de skill fourni) | — |

`transitions-ui-generation` (faire apparaître l'interface comme si une IA la dessinait) n'est pas repris : il ne sert pas
à Ravitaille.

Pour mettre à jour un skill : recopier son dossier depuis le dépôt d'origine.
